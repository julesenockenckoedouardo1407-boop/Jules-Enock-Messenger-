JULES ENOCK MESSENGER v1.0

Cette version est une PWA : elle peut être installée sur Android depuis le navigateur.

Installation :
1. Mettre tous les fichiers à la racine d'un dépôt GitHub.
2. Activer GitHub Pages sur la branche contenant index.html.
3. Ouvrir l'adresse GitHub Pages sur Android.
4. Dans Chrome : menu ⋮ > Ajouter à l'écran d'accueil / Installer l'application.

Important :
Cette v1.0 utilise des données locales et des conversations de démonstration.
Elle ne permet pas encore à deux téléphones de s'envoyer réellement des messages.
La v2 ajoutera une base de données et la synchronisation en ligne.
